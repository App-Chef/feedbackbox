# 🌙 Dark Mode - Quick Start

Your application now uses **dark mode by default** with a simple toggle button.

## 🚀 Try It Now

1. Start the dev server:
   ```bash
   npm run dev
   ```

2. Open http://localhost:3000

3. You'll see a **dark interface** by default

4. Look for the **Sun icon (☀️)** in the top-right corner

5. Click it to switch to light mode

6. Click the **Moon icon (🌙)** to return to dark mode

## 🎨 How It Works

- **Default:** Dark mode
- **Toggle:** Single button (Sun/Moon icon)
- **Persistent:** Your choice is saved
- **No flash:** Theme loads instantly

## 📍 Toggle Location

The theme toggle button appears in:
- **Landing page:** Top-right header
- **Login/Signup:** Top-right corner
- **Dashboard:** Bottom of sidebar

## 🎯 For Users

**In Dark Mode (default):**
- Interface is dark
- See Sun ☀️ icon
- Click to switch to light

**In Light Mode:**
- Interface is light
- See Moon 🌙 icon
- Click to switch to dark
