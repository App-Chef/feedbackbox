# SEO Implementation Checklist

Use this checklist to track your SEO setup and ongoing optimization tasks.

## ✅ Phase 1: Technical Setup (Week 1)

### Immediate Actions
- [ ] **Create OG Image** (`/public/og-image.png`, 1200×630px)
  - Include logo and branding
  - Add compelling tagline
  - Optimize file size (< 500KB)
  - Save to `/public/og-image.png`

- [ ] **Google Search Console**
  - Sign up at https://search.google.com/search-console
  - Verify domain ownership
  - Submit sitemap: `https://your-domain.com/sitemap.xml`
  - Check for crawl errors

- [ ] **Verify Structured Data**
  - Test at https://search.google.com/test/rich-results
  - Validate at https://validator.schema.org/
  - Fix any errors or warnings
  - Verify all schemas appear correctly

- [ ] **Analytics Setup**
  - Choose: Google Analytics / Plausible / Fathom
  - Add tracking code
  - Set up goals for signups
  - Test data collection

- [ ] **Social Media Testing**
  - Facebook: https://developers.facebook.com/tools/debug/
  - Twitter: https://cards-dev.twitter.com/validator
  - LinkedIn: https://www.linkedin.com/post-inspector/
  - Fix any issues with previews

## 🚨 Red Flags to Watch

Alert! Fix immediately if you see:
- [ ] Sudden traffic drop (>30%)
- [ ] Manual penalty in Search Console
- [ ] Massive ranking drops
- [ ] Crawl errors increasing
- [ ] Page speed score <50
- [ ] Mobile usability errors
- [ ] Duplicate content issues
- [ ] Broken backlinks

## 🔧 Tools to Use

### Free Tools
- Google Search Console (essential)
- Google Analytics (or alternative)
- Google PageSpeed Insights
- Schema.org Validator
- Mobile-Friendly Test
- Bing Webmaster Tools

### Paid Tools (Optional)
- Ahrefs ($99/mo) - Best for backlinks
- SEMrush ($119/mo) - All-in-one
- Moz Pro ($99/mo) - Good alternative
- Surfer SEO ($59/mo) - Content optimization

### Browser Extensions
- MozBar (free) - Quick SEO metrics
- SEO Minion (free) - On-page analysis
- Keywords Everywhere (paid) - Keyword research
